# Changelog

All notable changes to the **Thru Counter Program** will be documented in this file.

This project follows a simple versioning format:

- **Major Version** – Significant changes or breaking updates.
- **Minor Version** – New features and improvements.
- **Patch Version** – Bug fixes and small improvements.

---

# Version 1.2.0 - Current Release

**Release Date:** July 2026

## New Features

- Added **Reset Counter** instruction.
- Added **Decrement Counter** instruction.
- Improved counter safety by preventing values below zero.
- Added support for emitting events after counter updates.

# Versioning Policy

The project uses the following version format:

```
MAJOR.MINOR.PATCH
```

Example:

```
1.2.0
```

Where:

- **MAJOR** – Breaking changes.
- **MINOR** – New functionality.
- **PATCH** – Bug fixes and documentation updates.
