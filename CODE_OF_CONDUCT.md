# Code of Conduct

## Our Pledge

We are committed to making participation in this project a welcoming and respectful experience for everyone.

We encourage collaboration, learning, and constructive feedback regardless of experience level, background, or identity.

---

# Our Standards

Examples of positive behavior include:

- Being respectful and professional.
- Welcoming new contributors.
- Giving constructive feedback.
- Being patient when helping others.
- Accepting different viewpoints.
- Focusing on improving the project.

---

# Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment or abusive language.
- Personal attacks.
- Discrimination of any kind.
- Trolling or intentionally disruptive behavior.
- Sharing private information without permission.
- Any conduct that creates an unwelcoming environment.

---

# Reporting Issues

If you experience or witness unacceptable behavior, please open an issue or contact the project maintainer.

Reports will be reviewed fairly and handled respectfully.

---

# Enforcement

Project maintainers may edit, remove, or reject comments, issues, pull requests, or contributions that violate this Code of Conduct.

Repeated violations may result in restricted participation.

---

# Scope

This Code of Conduct applies to:

- GitHub Issues
- Pull Requests
- Discussions
- Documentation
- Project communication
