# Thru Counter Program

A smart contract built with the **Thru SDK** in **C** that demonstrates on-chain state management using a simple counter account.

This project extends the basic Thru counter example by adding additional counter operations and improving the documentation.

---

## Features

- ✅ Create Counter
- ✅ Increment Counter
- ✅ Decrement Counter
- ✅ Reset Counter
- 🔄 Event Emission
- 📦 Account Creation & Management

## Quick Start

Clone the repository:

```bash
git clone git@github.com:Crescent21/Thru-counter-program.git
cd Thru-counter-program
```

Build:

```bash
make
```
